# Supabase storage bucket configured as public (unauthenticated read access)

## Threat

Supabase Storage lets teams create **public buckets** — any file stored there is
reachable via a plain unauthenticated HTTP GET:

```
https://<project>.supabase.co/storage/v1/object/public/<bucket>/<file>
```

No JWT, no RLS policy, no signed URL is required. Developers often flip
`public = true` during prototyping to skip the signed-URL flow and forget to
revert before production, permanently exposing every uploaded file (user avatars,
contract PDFs, medical images, financial documents) to the open internet.

Because Supabase Storage sits outside PostgreSQL's Row-Level Security system,
RLS policies on the `storage.objects` table do **not** restrict access to files
in a public bucket — the CDN serves them directly, bypassing the database layer
entirely.

**Impact:** Broken Access Control (OWASP A01). Any uploaded PII becomes world-
readable. A storage URL is guessable or enumerable (UUIDs are generated by the
client, often predictably seeded). Once a URL is shared or leaked, there is no
revocation mechanism short of deleting and re-uploading the file.

## Detection design

Two signals are detected. Both are suppressed file-wide by the pragma
`# security: allow-public-bucket`.

### Signal 1 — SQL migration (`sql-public-bucket`)

Regex: two conditions on the same SQL line (after comment stripping):

```
INSERT\s+INTO\s+storage\s*\.\s*buckets\b   (anchor: Supabase bucket insert)
\bpublic\s*=\s*true\b                       (flag: public flag set to true)
```

Both regexes are case-insensitive. SQL comments are stripped before matching so
`-- public=true` in a comment does not trigger. Applied to `.sql` files found
anywhere under the repository root.

### Signal 2 — Python SDK (`python-public-bucket`)

Regex: two conditions on the same Python line:

```
supabase\s*\.\s*storage\s*\(\s*\)\s*\.\s*create_bucket\s*\(
    (anchor: supabase-py SDK call)
["']public["']\s*:\s*True\b | (?<!\w)public\s*=\s*True\b
    (flag: public kwarg or dict key set to True)
```

Applied to `.py` files in `python_scan_dirs` (profile-detected Python dirs,
fallback: repo root). One finding per file maximum.

### Signal 3 — JS/TS SDK (`js-public-bucket`)

```
\bcreate[Bb]ucket\s*\(              (anchor: supabase-js SDK call)
["']public["']\s*:\s*true\b         (flag: JS object property set to true)
```

Applied to `.js`, `.ts`, `.jsx`, `.tsx` files under root. One finding per file.

## Severity rationale

**HIGH.** Public bucket exposure is not theoretical — the file is already
accessible once the bucket is created. There is no authentication barrier.
Combined with the fact that users upload sensitive documents to buckets precisely
because they expect them to be private, this is a high-severity broken-access-
control finding per OWASP A01 and CIS Benchmark 6.3 (restrict storage access to
authenticated identities).

## Known bypasses

| Bypass | Coverage status |
|--------|----------------|
| Multi-statement SQL: `public` flag set in a preceding `UPDATE` after a private INSERT | Not detected — requires dataflow / multi-statement analysis |
| `public` flag set via Supabase Dashboard UI (no code artifact) | Not detectable statically — covered by Splinter live-scan |
| Environment variable expansion: `public = ${IS_PUBLIC}` resolving at runtime | Not detected — requires runtime value analysis |
| Supabase edge functions calling the management API | Not detected — requires JS analysis of edge function payloads |
| Bucket created via Terraform / Pulumi IaC | Not detected — IaC guard would need a separate signal |

## FP scenarios

| Scenario | Why it is a false positive | Verdict |
|----------|---------------------------|---------|
| `INSERT INTO storage.buckets ... public = false` | `_SQL_PUBLIC_TRUE` does not match `false` | Not fired (regex is `true` only) |
| `supabase.storage().create_bucket("docs", {"public": False})` | `_PY_PUBLIC_TRUE` requires `True` (capital T) | Not fired |
| Comment containing `public = true` above an unrelated statement | `strip_sql_comments` removes `--` and `/* */` blocks | Not fired |
| A Python variable named `public_true_flag` | `\b` word boundary on `True` prevents partial match | Not fired |
| `# security: allow-public-bucket` present anywhere in file | Entire file skipped | Suppressed |
