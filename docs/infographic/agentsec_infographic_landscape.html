How It Works

1. Point to Your Repo

The process begins by simply pointing the CLI at your code repository—no complex setup required.

2. Fingerprint Your Stack

agentsec automatically identifies your tech stack (e.g., FastAPI, Supabase, Stripe, LangChain) via manifest and AST analysis.

3. Run Targeted Checks

It activates only the guards that apply to your specific tools, running 493 static guards and optional external scanners in parallel.

4. Score & Prioritize

Findings are scored by severity × reachability, filtering out issues in non-product code like test files or migration scripts.

[ACTION] Lethal Trifecta found in agent_loop.py — LLM has autonomous tool access without a human gate.

5. “Fix These First” Report

It emits a prioritized report.

6. CI Gate Security

The CI/CD integration automatically blocks the Pull Request if any “HIGH” or “CRITICAL” vulnerabilities are detected.

What Makes It Special

Knows AI Threats

Specifically covers the OWASP LLM Top 10 (2025) — e.g. LLM05 Improper Output Handling — detecting flaws like “LLM output passed to exec()” and the Lethal Trifecta.

No False Alarms by Design

If you don’t use Stripe, the payment guards don’t fire. A clean report means nothing was found, not just that nothing was checked.

Zero Dependencies to Start

Run pipx install ai-agent-security and you’re ready; it uses built-in guards first, making external scanners like Semgrep or Bandit optional.

Static + Live

Beyond reading code, it runs black-box scans against your running app — OWASP ZAP (DAST), Supabase Splinter DB-lint, OpenAPI fuzzing, and JWT / LLM red-team — all merged into the same report.

Fixes, Not Just Findings

It doesn’t just report: agentsec fix applies safe, diff-first mechanical fixes and hardens your dependencies (cooldown + hashed lock + lifecycle-script blocking). Nothing auto-commits — you review the diff.

Offline by Default

Tier 0 sends nothing off your machine. The few scanners that fetch advisories are skipped unless you explicitly opt in with --network tier1.

Proof & Performance

Security exceptions (ignores) expire. If you acknowledge a risk, it will resurface after a set date to ensure it isn’t forgotten.
